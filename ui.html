Карточка товара

По карточкам ЧЗ отвечает на запросы о товаре (product/info), а 1С видит их через API Национального каталога. GTIN без карточки ЧЗ «не знает». Нажмите строку в списке, чтобы изменить карточку.

Импорт из CSV / Excel

Колонки через «;» или табуляцию: GTIN; Наименование; ТГ; ТН ВЭД; Бренд; ИНН; Статус. Можно вставить строки, скопированные из Excel. Строки без GTIN (например, заголовок) пропускаются.

Автосценарий: полный цикл ЧЗ

Проходит через прокси и TLS эмулятора так же, как 1С: авторизация → участник → СУЗ (соединение, заказ, коды, отчёт о нанесении) → ввод в оборот → агрегация → отгрузка → приёмка → вывод из оборота → разрешительный режим. Участники 7799000001 и 7799000002, данные остаются в эмуляторе.
