Подключение 1С

Один раз на базу. Подробно — в ИНСТРУКЦИЯ.md рядом с эмулятором.

  1. Доверить сертификат эмулятора на компьютере, где работает сервер 1С: скачать ca.crt, затем certutil -user -addstore Root ca.crt (для службы сервера 1С — без -user, от администратора).
  2. Тестовый контур: НСИ и администрирование → Интеграция с ИС МП (обувь, одежда, табак...) → вкладка «Электронные подписи и авторизация» → флажок «Тестовый контур».
  3. Прокси 127.0.0.1:3128: файловая база — Персональные настройки → «Настройка доступа к Интернету» (у каждого пользователя); клиент-серверная — Общие настройки → «Параметры прокси-сервера». Задаётся в тонком клиенте, не в веб-клиенте.
  4. СУЗ: адрес suz.sandbox.crptech.ru, порт 443, защищённое соединение, omsId — любой.
  5. Нет ЭП? Скачать расширение «ЧЗ_БезПодписи» → Администрирование → Печатные формы, отчёты и обработки → Расширения → «Добавить из файла», снять «Безопасный режим», перезапустить 1С. Работает только при включённом тестовом контуре.
  6. Обработки 1С (Файл → Открыть, или подключить как дополнительные): «Настройка подключения к эмулятору ЧЗ» — тестовый контур, прокси, СУЗ и регистрация организации одной кнопкой; «Выгрузка GTIN номенклатуры в Нац. каталог».
  7. Проверить: любое действие с ЧЗ в 1С — запросы появятся в «Журнале».

Карточка товара

По карточкам ЧЗ отвечает на запросы о товаре (product/info), а 1С видит их через API Национального каталога. GTIN без карточки ЧЗ «не знает». Нажмите строку в списке, чтобы изменить карточку.

Импорт из CSV / Excel

Колонки через «;» или табуляцию: GTIN; Наименование; ТГ; ТН ВЭД; Бренд; ИНН; Статус. Можно вставить строки, скопированные из Excel. Строки без GTIN (например, заголовок) пропускаются.

Автосценарий: полный цикл ЧЗ

Проходит через прокси и TLS эмулятора так же, как 1С: авторизация → участник → СУЗ (соединение, заказ, коды, отчёт о нанесении) → ввод в оборот → агрегация → отгрузка → приёмка → вывод из оборота → разрешительный режим. Участники 7799000001 и 7799000002, данные остаются в эмуляторе.
